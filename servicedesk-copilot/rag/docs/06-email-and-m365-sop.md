# SOP – Email and Microsoft 365 Issues

## Outlook not receiving email

1. Check the service health dashboard for an ongoing Microsoft 365 incident.
2. Ask the user to check webmail (Outlook on the web). If mail arrives there, the problem is the desktop client: restart Outlook, then repair the Office installation.
3. If mail is missing in webmail too, check the mailbox size; mailboxes over 99% of quota stop receiving mail. Ask the user to archive or delete items, or request a quota increase through Product Support.

## Shared mailbox access

Access to a shared mailbox needs approval from the mailbox owner. After approval, add the user in the admin console; access can take up to 60 minutes to appear in Outlook.

## Suspected phishing email

Tell the user not to click links or open attachments. Ask them to use the "Report phishing" button. If they already entered their password on a suspicious page, reset the password immediately, revoke active sessions and inform Security as a possible security incident.

## Teams calls quality

Poor call quality is usually a network problem. Ask the user to test on a wired connection and close bandwidth-heavy applications. If an entire site is affected, escalate to Technical Support.
