# TechServ Data Privacy and Security Policy for Support Staff

## Handling personal data in tickets

- Collect only the personal data needed to resolve the ticket.
- Never ask customers to send passwords, full card numbers or national ID numbers. If a customer sends them, redact them from the ticket and tell the customer to change the password.
- Personal data must not be pasted into external tools. The AI copilot masks personal data automatically before any text is sent to an external language model.
- Ticket data is retained for 24 months after closure and then deleted or anonymised.

## Security incidents

A security incident is any suspected unauthorised access, data leak, malware infection or phishing compromise.

1. Report it immediately to the Security team through the security hotline or the "Security incident" ticket category; never handle it only in a normal queue.
2. Do not delete evidence such as emails or logs.
3. Security assesses the incident within 1 hour and decides whether it is a personal-data breach.
4. Confirmed personal-data breaches are reported to the relevant data-protection authority within 72 hours, and affected customers are informed without undue delay.

## Access to customer systems

Agents may access customer systems only for an open ticket and only with the customer's approval recorded in the ticket. Remote sessions must use the approved remote-support tool, which records the session.
